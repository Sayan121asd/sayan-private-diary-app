# Nirbhor Diary — Private Bangla & English Note Vault

**✨ Made by Sayan ✨**

A responsive, single-page **Private Note-Taking & Secret Diary Web Application** built with **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**.

## Features
- **Multi-Account Secret Vault (`localStorage`)**:
  - Create multiple user accounts with unique **Account ID / Username** and **Password / PIN**.
  - Each user account has its own isolated private notes vault.
  - Built-in **Change PIN / Password** and **Logout / Switch ID** support.
- **Real-Time Avro Phonetic (Banglish to Bangla) Typing Engine**:
  - Toggle between **Bangla (Avro Phonetic)** and **English** (`Ctrl + M`).
  - Instant live Bangla conversion as you type (supports both lowercase and uppercase/CAPS LOCK typing).
  - Live floating candidate preview with offline Avro phonetic rules, natural Banglish dictionary, and Google Input Tools transliteration support.
- **Note Management (CRUD)**:
  - Create, edit, search/filter (in Bangla or English), and delete notes with confirmation.
  - Real-time auto-save and `.txt` file export.
  - Dark & Light mode support using Google Fonts (`Hind Siliguri`, `Noto Sans Bengali`, `Inter`).

## Run Locally
Simply open `index.html` in any modern web browser.
